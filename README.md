## 一、先把"IEPL / IPLC / IX"拆开说

很多人把这三个名字当成性能阶梯，实际上它们只是不同形态的专线接入：

- **IEPL（International Ethernet Leased Line，国际以太网专线）**：基于以太网二层技术，带宽弹性好，但稳定性、抖动和价格要按实际方案看。MKCloud 的 IEPL 目前只做广港（广州→香港方向），端内参考延迟 1~2ms。
- **IPLC（International Private Leased Circuit，国际私有租用线路）**：传统意义上的"专线"。MKCloud 的 IPLC 覆盖沪港（21ms）、沪日（25~28ms）、沪美（124~134ms），以及厦港、泉港等福建高防 IPLC。
- **IXP（Internet Exchange Point，互联网交换点）**：通过阿里云/腾讯云/UCloud 等云厂 BGP 内网接入，不限连入省份。MKCloud 的深港 IX 起步价是全站最低的 ¥158/月，但需要自己准备一台支持范围内的云前置机。

按 MKCloud 官方口径，**三者不是性能排序**。同名字也可能因入口、计费、配置不同而体验差异巨大。所以选型不能只看名字和延迟数字，要按业务目标倒推。

## 二、订购前必须确认的 5 件事

按 MKCloud 知识库的 60 秒选型表，选购前要依次回答五个问题：

1. **业务能不能在 VPS 内运行？**
 MKCloud 专线出口**不接受外部连入**，不能用作公开网站、邮件接收、支付回调或游戏服务端。出口仅用于"由 VPS 主动向外访问"。如果业务必须接收公网连接，这条方案直接不适用。

2. **目标出口在哪里？**
 香港（Shopee/eBay）、日本（Rakuten/TikTok 日区）、美国（Amazon 美区/TikTok 美区/独立站）三种方向延迟差异极大：

   | 线路 | 端内参考延迟 | 主要用途 |
   | --- | --- | --- |
   | 广港 IEPL | 1~2ms | 华南团队对港电商 |
   | 沪港 IPLC | 21ms | 长三角电商后台、办公 |
   | 沪日 IPLC | 25~28ms | 日本电商、游戏测试 |
   | 深港 IX | 1~2ms | 需要云前置 + 香港出口 |
   | 沪美 IPLC | 124~134ms | 美区亚马逊、独立站后台 |
   | 厦港/泉港 IPLC | 1~2ms | 福建团队 + 高防需求 |

3. **从本地宽带连，还是已经有云厂机器？**
 直连（IEPL/IPLC）只能从绑定的省份 IP 连入。如果团队在 A 省而绑定的是 B 省，连不上。IX 产品不限省份，但必须从支持范围内的云网络接入（阿里云、腾讯云、百度云国内全网 + UCloud / 华为云 / 火山云指定区域）。

4. **看峰值还是看持续速率？**
 共享带宽套餐**只标注峰值，不保证持续跑满**。如果业务是 24h 持续上传、推送，那就需要选独享带宽套餐（不限流量）。

5. **是否需要高防、SLA、特定路由？**
 福建方向（厦港/泉港）自带 100~300Gbps DDoS 高防；标准套餐默认无 SLA，需要保障请走工单咨询定制。

## 五、必须看清的几个使用限制

### 1）仅支持支付宝支付
MKCloud 当前官网 FAQ 明确写了"目前只支持支付宝进行付款"。有外卡/对公账户需求的话要提前沟通。

### 2）必须实名认证（国内身份）
专线 VPS 业务合规要求：**国内手机号 + 身份证 + 邮箱**三重验证。仅限个人或企业正规用途。PUSH、改价、独享等活动环节会人工审核。

### 3）默认不接受公网入站
不是公开网站方案。出口 IP 主动发起访问才是它的工作模式。如果要做对外服务、公开站点、邮件接收、支付回调，**这条方案不适合**。

### 4）默认无 SLA 保证
标准产品口径是"约 1 分钟自动开通、无路政审批"，但延迟、可用性不构成 SLA 承诺。需要 SLA 或路由定制要单独询价。

### 5）退款极严
官方口径是 **"仅质量问题"** 支持退款，需要提交测试截图与具体问题工单审核，开通后无法更换地域。等于**不是试用制**，反过来也就意味着先想清楚再下单。

### 6）直连绑省份、IX 要云网络
直连产品绑定一个连入省份，切换省份有流程和冷却。IX 产品必须从阿里云 / 腾讯云 / UCloud / 百度云国内全网 + 火山云 / 华为云指定区域内网接入。

### 7）共享带宽是峰值
300Mbps 共享套餐并不代表能持续跑满 300Mbps。长途传输或实时推流场景通常要选独享型。

## 七、什么人不适合买 IPLC 专线

- **预算 × 普通个人浏览**：用不着 1~2ms 端内延迟，CN2 GIA 或普通优化 VPS 就够了。
- **要公开建站**：专线 VPS 出口不接受入站串流，不适合做公开网站。
- **拿来做翻墙机场主**：MKCloud 服务条款明确仅限个人或企业正规用途，机场转发有可能触发人工审核甚至停机。
- **不愿走实名认证**：IEPL/IPLC 全部要求国内实名。

4. 支付（仅支付宝）→ 约 1 分钟自动开通。IX 套餐需提前准备前置云机。
5. 取入口地址、账号、RDP/SSH 远程桌面登录 → 在 VPS 内运行浏览器或业务程序，出口自动走专线。
6. 售后问题优先走工单；客服高峰期响应不快，但技术团队工单处理通常更高效。

> MKCloud 知识库中明确："禁止违法用途；不限制 TCP/UDP/端口/并发数量，但用途必须合规。"换句话说，工具不做恶，平台才不会拒绝继续为你服务。

## 九、参考小结

把上面信息压成一句话：**想用 IPLC 专线，重点不是名字，而是方向、入口、用量、可持续性**。

如果你的业务刚好落在下面几条，MKCloud 这类合规专线 VPS 是值得放进候选清单的：

- 华南/长三角/福建团队，需要从国内直连访问海外电商后台；
- 跨境电商多账号管理，需要双端独立 IP、固定出口 IP；
- 跑 TikTok 直播推流、Shopify 独立站运营、海外 SaaS 数据同步；
- 不想再为丢包和延迟反复排查，换个端到端可控的网络。

如果是别的场景，先把"业务能否在 VPS 内运行 + 公网入站需求 + 月流量 + 持续速率"四个问题想清楚再看专线会更省事。
